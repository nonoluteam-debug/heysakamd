## Tentang Proyek

**HeySaka Multi Device** adalah bot Telegram inovatif yang dirancang untuk memenuhi berbagai kebutuhan digital Anda. Dengan dukungan **multi-device**, bot ini dapat beroperasi secara optimal di berbagai platform dan perangkat, memberikan pengalaman yang mulus, responsif, dan selalu siap sedia.

Selain bot itu sendiri, proyek ini juga menyertakan **landing page modern** (`index.html`) yang menampilkan profil bot, tautan resmi, informasi lengkap, dan fitur interaktif seperti **ganti tema** dan **multi-bahasa** - semuanya berjalan murni di browser tanpa backend.

> **Filosofi:** Sederhana, cepat, indah, dan berfungsi penuh - bahkan tanpa server.

## Cara Menggunakan

### 1. Clone / Download

```bash
# Clone repository
git clone https://github.com/username/heysaka-multi-device.git

# Atau download ZIP
# Klik tombol "Code" -> "Download ZIP" di GitHub
```

2. Buka di Browser

```bash
# Cukup klik dua kali index.html
# Atau gunakan live server:
npx serve .
```

3. Nikmati Fitur

· Klik ikon palette untuk ganti tema
· Klik ID / EN / AR untuk ganti bahasa
· Klik tombol link untuk membuka Telegram

---

Kustomisasi

Ganti Foto Profil

Cari baris berikut di index.html:

```html
<img class="avatar"
     src="https://ganga--link--ghhzdp9sv8hk.code.run/i/bhtihds8"
     alt="HeySaka Profile">
```

Ganti src dengan URL gambar Anda.

Ganti Tautan

Cari class .link-btn dan ubah href:

```html
<a href="https://t.me/heysakamdbot" class="link-btn">
```

Tambah Tema Baru

1. Tambahkan variabel CSS di :root:

```css
body.theme-mytema {
  --bg: #yourbg;
  --accent: #youraccent;
  /* ... */
}
```

2. Tambahkan chip di panel tema:

```html
<button class="theme-chip" data-theme="mytema" onclick="setTheme('mytema')">
  <span class="swatch" style="background:linear-gradient(135deg,#c1,#c2)"></span>
  <span>Nama Tema</span>
</button>
```

3. Tambahkan ke array validasi di JS:

```javascript
if (['light','dark','chess','blue','green','purple','red','mytema'].includes(savedTheme))
```

Tambah Bahasa Baru

Tambahkan objek baru di I18N:

```javascript
const I18N = {
  id: { /* ... */ },
  en: { /* ... */ },
  ar: { /* ... */ },
  ja: {
    topbar_status: "オンライン · マルチデバイス",
    // ... terjemahkan semua key
  }
};
```

Lalu tambahkan tombol bahasa di HTML:

```html
<button class="lang-btn" data-lang="ja" onclick="setLang('ja')">
  <i class="fas fa-globe"></i> JP
</button>
```
