# HeySaka Multi Device

Bot Telegram canggih dengan dukungan multi-device, fitur lengkap, dan performa super cepat.

## Fitur

- Multi device support
- 7 tema warna (Light, Dark, Chess, Blue, Green, Purple, Red)
- 3 bahasa (Indonesia, English, Arab)
- Responsive dan ringan
- Tanpa backend, tanpa dependency
